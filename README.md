# CINCO — futebol comunitário em Angola

O **CINCO** é um projeto de aplicação web progressiva (PWA), pensado primeiro para telemóveis, que ajuda comunidades em Angola a organizar atividades de futebol e encontrar formas de jogar.

## O que pretende facilitar

A organização de uma partida envolve encontrar um campo, combinar horário e modalidade, reunir participantes e partilhar os detalhes. O CINCO reúne estas tarefas numa experiência digital acessível e orientada para o uso em dispositivos móveis.

## Funcionalidades previstas no projeto

- **Campos e reservas:** consultar campos, modalidades, preços e horários disponíveis, e gerir reservas.
- **Peladas:** organizar partidas, definir data, hora e número de vagas e acompanhar participantes.
- **Modalidades:** apoiar diferentes formatos, incluindo futebol de 5, de 7 e de 11, futsal e futebolina.
- **Descoberta e comunidade:** apresentar atividades e informações relacionadas com a comunidade de futebol.
- **Partilha:** facilitar a divulgação de partidas e convites, incluindo partilha por WhatsApp.
- **Experiência móvel:** interface adaptável a telemóveis e recursos de PWA.

As funcionalidades disponíveis podem variar conforme o ambiente e a fase de desenvolvimento. Esta página é uma apresentação do projeto, não uma oferta de serviço nem uma confirmação de que todas as funções estão publicadas.

## Para quem

O projeto é pensado para jogadores, organizadores de partidas e responsáveis por campos que queiram coordenar atividades de futebol comunitário.

## Tecnologia

O projeto privado da aplicação utiliza tecnologias web como **TypeScript, React e Vite**. A arquitetura e o alojamento continuam em avaliação; esta apresentação pública não inclui código-fonte, credenciais, dados de utilizadores nem configurações de produção.
